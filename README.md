## 什么是 Onvord？

**Onvord** 是一款 Chrome 扩展，帮助你通过「边操作边说话」的方式，自动录制浏览器操作流程，生成结构化的 SOP（标准操作文档）。

生成的 SOP 不仅**人能看懂**（图文并茂、步骤清晰），还能**直接发给 AI Agent 执行**（包含精确的 CSS 选择器和操作语义）。

当前仓库包含原商业版 `0.5.19` 的完整 Chrome 扩展客户端源码，并以 MIT License 开源。

> 🎯 **一句话理解**：你做一遍，AI 帮你做一万遍。

## 功能特性

### 🎙️ 实时语音转文字
- 基于 **官方托管的阿里云实时语音方案**，开箱即用
- 当前提供 **中文（zh-CN）/英文（en-US）** 识别配置
- 用户无需填写第三方 API Key，语音讲解自动关联到对应操作步骤（无意义文本会自动过滤）

### 🖱️ 智能操作捕获
- 自动记录点击、输入、滚动、页面导航
- **文字选择** vs **点击** 精准区分
- 智能过滤无意义操作（空白区域点击等）
- 自动识别元素类型（按钮、链接、输入框、图标等）

### 📸 缩略图截图预览
- 当前对 **点击（click）/选择（select）** 自动截图并标注点击位置
- 截图以小缩略图嵌入操作标签内（录制中与录制后一致）
- 点击缩略图可弹层放大查看

### 📋 单页混合时间线
- **录制中** 与 **停止后预览** 使用同一套时间线视图，避免来回切页
- **语音** → 连续合并为段落，占位提示为「识别中」
- **操作** → 紧凑标签式排列，滚动支持合并展示（如 `滚动 xN`）

### 📄 独立网页导出
- 一键导出为自包含 HTML 文件
- 图文并茂，包含步骤截图与讲解分段
- 可直接发送给他人或上传给 AI Agent
- 内置文档说明与「执行细节（给 Agent）」，AI 拿到即懂

## 快速开始

### 1. 安装

> 目前为开发者预览版，需手动加载。

1. 下载本项目代码
2. 打开 Chrome → `chrome://extensions/`
3. 开启「开发者模式」
4. 点击「加载已解压的扩展程序」→ 选择项目文件夹

### 2. 连接官方服务

1. 首次打开侧栏时，扩展会自动向官方服务完成设备注册
2. 客户端会自动获取本次录制所需的临时语音会话信息
3. 如果服务不可用，可在扩展设置页查看连接状态并重新连接

### 3. 开始录制

1. 打开要演示的网页
2. 点击浏览器工具栏 Onvord 图标打开侧栏
3. 点击 **⏺ 开始录制**
4. 正常操作浏览器，同时用语音讲解每一步
5. 完成后点击 **⏹ 停止录制** → 自动生成 SOP
6. 如需分享，点击 **导出 SOP** 下载独立 HTML 文件

## 开源范围与托管服务

- 本仓库开源的是 **Onvord Chrome 扩展客户端**，包含录制、时间线、截图、导出、账号和订阅界面等完整客户端代码。
- 客户端默认连接 `https://api.onvord.com`，用于设备会话、账号、订阅状态和临时语音凭证。该托管服务及第三方服务不属于本仓库，也不受本仓库 MIT License 约束。
- 当前仓库**不是完整的自托管方案**：兼容服务端需要实现 `commercial.js` 中调用的接口；服务端参考实现尚未包含在本仓库中。
- 代码中的 `commercial*` 命名为兼容已有用户的本地数据与接口而保留，不代表客户端源码仍是闭源的。

## 技术架构

```
┌─────────────────────────────────────────────┐
│  Chrome Extension (Manifest V3)             │
├──────────────┬──────────────┬───────────────┤
│ content.js   │ sidepanel.js │ background.js │
│ · 捕获操作    │ · 单页时间线 UI│ · 状态管理     │
│ · 元素描述    │ · 托管语音 STT │ · SOP 生成    │
│ · 事件过滤    │ · 导出网页     │ · 截图标注     │
└──────────────┴──────────────┴───────────────┘
         │                          │
    ┌────┴────┐              ┌──────┴──────┐
    │ Cloudflare│            │ Offscreen   │
    │ Worker API│            │ Canvas      │
    │ + Aliyun  │            │ (标注截图)   │
    └──────────┘              └─────────────┘
```

- **content.js** — 注入页面，捕获用户操作（点击、输入、文字选择）
- **sidepanel.js** — 侧栏 UI，录制/预览统一时间线、官方托管语音识别、SOP 导出
- **background.js** — Service Worker，管理录制状态、生成 SOP、截图标注
- **annotate.js** — Offscreen 文档，在截图上标注点击位置

## 隐私与安全

- 🔒 **无需用户 API Key** — 用户侧只保存设备标识和会话信息，不需要管理第三方语音密钥
- 🔒 **语音数据** — 由官方服务下发语音会话后连接阿里云实时语音处理，扩展不做本地持久化存储
- 🔒 **截图数据** — 所有截图仅在本地处理，不离开你的浏览器
- 🔒 **客户端开源** — 扩展客户端代码可自行审计；托管服务边界见上文说明
